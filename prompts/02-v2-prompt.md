# 实验四 V2 迭代提示词

请基于已经可以完整游玩的 V1 继续迭代，保留 3 套题库、12 张卡片配对棋盘、知识解释和结算弹窗，不重做核心玩法。

## V1 已验证

- 《论语》篇默认加载 12 张卡片。
- 3 套题库可以切换。
- 正确配对会锁定卡片、增加得分并显示知识解释。
- 错误配对会短暂标红并清空连对。
- 完成 6 组后会出现结算弹窗。
- 桌面端和手机端无横向溢出。

## V1 实际测试发现的问题

1. 游戏没有音效，正确、错误和完成反馈主要依赖颜色与文字。
2. 学生卡住时没有提示，可能长时间停留在同一轮。
3. 计时开始后无法暂停，课间或临时离开时会持续计时。
4. 错误反馈只说明配对失败，没有指出可以观察的关键词。
5. 每套题库的最佳成绩只保存在单独的本地记录中，页面内没有统一成绩册。
6. 结算没有展示提示次数，无法判断成绩是否借助过提示。

## V2 修改目标

### 1. 加入声音反馈

- 使用 Web Audio API 生成正确、错误、提示和完成音效，不加载外部音频文件。
- 顶部增加声音开关，默认开启。
- 声音开关状态保存到 `localStorage`。

### 2. 增加智能提示

- 顶部增加“提示”按钮，每局最多使用 3 次。
- 点击后自动高亮一组尚未匹配的正确卡片，持续 2.5 秒。
- 每使用一次提示扣除 15 分，并在结算中显示提示次数。
- 3 次用完后按钮禁用，并显示剩余次数。

### 3. 增加暂停和继续

- 本局开始后可以暂停计时和点击操作。
- 暂停时棋盘降低透明度并显示暂停状态，按钮切换为“继续”。
- 暂停期间不能选择卡片，恢复后继续原局。

### 4. 改进错误反馈

- 配对错误时分别标明两张卡片的类型和内容。
- 引导用户关注原句中的关键词、实词位置或成语寓意。
- 错误状态持续时间由 760ms 延长到更易感知的 900ms。

### 5. 增加成绩册

- 右侧增加 3 套题库的成绩册。
- 展示每套题库的历史最快用时和最高得分。
- 完成本局后立即刷新成绩册，并标记出是否刷新个人纪录。

### 6. 优化移动端

- 顶部操作按钮在手机端不换行、不遮挡。
- 2 列棋盘在 320px 宽度下仍能完整显示卡片文字。
- 暂停和提示控件在触屏下保持足够点击面积。

## 输出要求

保留 V1 独立快照，将 V2 代码放在仓库根目录。提供 V2 桌面端、手机端截图和一段短操作演示。
